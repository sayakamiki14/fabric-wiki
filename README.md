# 布料與洗標小百科 🧵

服裝設計系學生整理的小百科網站：**一頁看懂一種布料、一組洗標符號或一條服飾標示規定。**

- 網站：https://sayakamiki14.github.io/fabric-wiki/
- 作者：實踐大學 服裝設計學系 陸宥辰（TAICA 生成式 AI 第九週作業）

## 這個專案的重點：CLAUDE.md

[`CLAUDE.md`](CLAUDE.md) 是寫給 AI 看的專案規則，內容包含：

1. 專案目的、讀者與語氣
2. 檔案結構與三個固定分類（布料／洗標／標示法規）
3. 檔名規則：`pages/<分類>/<英文小寫-連字號>.html`
4. 新增頁面的 7 個步驟（複製範本 → 填內容 → 登記到 `data/pages.json` → 加雙向連結 → 檢查）
5. 每個分類的「固定段落」
6. 內容正確性規則：法規數字只能來自〈服飾標示基準〉
7. 視覺風格與完成檢查清單

只要對 AI 說「**請依照 CLAUDE.md 新增一頁布料：○○**」，AI 就能做出格式一致的新頁面，首頁也會自動出現卡片。
